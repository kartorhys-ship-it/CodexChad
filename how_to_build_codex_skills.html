01 / Core Mental Models

What Actually Is a "Skill"?

Understanding the philosophical difference between blind AI generation and standard operating procedures (SOPs).

🥞

The Chocolate Chip Pancake Analogy

Imagine a world-famous master chef who bakes the most extraordinary chocolate chip pancakes. If you simply ask someone to "make pancakes", you might receive silver-dollar pancakes, burnt pancakes, or thin crepes.

Chef's End Deliverable: The North Star / Definition of Done.
The Written Recipe: The SKILL.md file (exact ingredients, heat, timing, sequence).
The Agent's Role: Executes the recipe without guessing what Nate prefers.

Without a skill, an agent improvises blindly. With a skill, the agent replicates world-class execution every single time.

📄

Anatomy of a SKILL.md File

A skill is a pure, portable CommonMark markdown file composed of two distinct architectural tiers:

1. YAML Frontmatter (Metadata Header) --- delimited

Parsed by the agent orchestrator without reading the full file. Defines the name, the exact description & trigger conditions, and parameter hints.

2. Instruction Body (The Meat) Markdown #, -, 1.

Loaded into context *only after* the skill is triggered. Contains the step-by-step logic, heuristics, tool invocation guidelines, and mandatory verification gates.

Storage: .agents/skills/ or .claude/skills/ 100% Portable

03 / Quality Assurance Architecture

Objective vs. Subjective Verification

Why your agent must never present you with a raw "Version 1" draft, and how to program LLM-as-a-Judge audits.

Deterministic Rules Binary: Pass / Fail

Objective Verification

Checks that can be mathematically or programmatically proven. Rules where $x = y$ or $count \ge N$.

✓
Exact Source & Citation Pipeline
Pull 500 sources $ ightarrow$ filter to top 250 $ ightarrow$ have Agent 2 check every factual claim.
✓
Structural & Count Gates
Minimum 7 H2 sections, exactly 10 screenshots, zero empty text blocks.
✓
Deterministic Formatting Assertions
Verify JSON schema compliance, file path existence, link 200 HTTP response codes.
LLM-as-a-Judge Qualitative: 1-10 Rubric

Subjective Verification

Checks requiring aesthetic judgment, contextual nuance, visual inspection, and brand alignment.

★
Visual Asset Curation (Multimodal)
Agent inspects captured screenshot: Is it caught mid-animation? Is it cropped tightly to the focal point?
★
Privacy & Sensitive Data Scrubbing
Are customer emails, internal API tokens, or demo billing receipts redacted with solid black blocks?
★
Voice, Flow & Cadence Alignment
Does this sound authentic to Nate's writing style guide, or does it reek of generic AI jargon?

05 / Production Blueprints

Copy-Ready Skill & Feedback Templates

Use these exact templates to scaffold your next skill and operationalize the Bike Method feedback loop.

Production SKILL.md Template 
---
name: video-to-x-article
description: Use this skill whenever the user asks to turn a YouTube video into a long-form X (Twitter) article.
argument_hint: [YouTube URL or Video File Path]
---

# Video to X Article Transformation Skill

## 1. Goal & Definition of Done
Transform the provided video into an engaging, publication-ready X article following Nate's voice and visual standards.
The output is DONE only when:
1. Article text is drafted in punchy, direct cadence.
2. 8-12 clean screenshots are cropped, spotlighted, and embedded.
3. Sensitive customer details or internal tokens are redacted.
4. QA Verification Report is generated and passes all criteria.

## 2. Freedom Level & Operating Mode
- Mode: Non-Deterministic / High Judgment (Content & Visuals).
- Strict Deterministic Constraints: Privacy redaction, max 1 image per text block, minimum 7 H2 sections.

## 3. Workflow Steps
1. Transcribe & Outline:
   - Extract transcript, extract key takeaways, establish 3-5 narrative pillars.
2. Draft Article:
   - Write clear, engaging H2 headers. Keep paragraphs to 1-3 sentences.
3. Visual Extraction (Browser / Tool Use):
   - Review video keyframes. Select clean, non-transition frames.
   - Crop to focal area; add spotlights to key numbers/charts.
   - Redact all sensitive receipts/IDs with black boxes.
4. Layout & QA:
   - Insert images directly beneath corresponding narrative sections.
   - Never stack multiple images consecutively.

## 4. Verification Loop (Mandatory QA)
Output formal QA Report before presenting final result:
- [ ] 8 to 12 inline screenshots verified
- [ ] At least 5 distinct H2 sections
- [ ] 0 exposed private receipts / IDs
- [ ] Subjective: No mid-animation or blurry frames
- [ ] Subjective: Conversational, punchy human tone
The "Bike Method" Feedback Prompt 
[Agent Name], here is my operational critique on your latest run:

WHAT WORKED WELL:
- [Praise specific element: e.g., "The spotlight on the pricing chart was sharp and accurate."]
- [Praise specific tone: e.g., "The opening hook was concise and punchy."]

WHAT FAILED / REQUIRES CORRECTION:
- [Specify error 1: e.g., "In Section 2, the screenshot was taken mid-animation and looks blurry."]
- [Specify error 2: e.g., "You stacked 4 images at the end of the post without descriptive text."]
- [Specify error 3: e.g., "The opening title was duplicated into the first body paragraph."]

MANDATORY ACTION:
1. Analyze this critique and explain WHY this breakdown occurred.
2. Update your `SKILL.md` file permanently so that:
   - Specific guardrails prevent these exact failure modes.
   - The verification checklist is updated to catch this automatically.
3. Show me the diff of `SKILL.md` before proceeding.
The Golden Rule: If you manually fix an agent's mistake without telling it to update SKILL.md, you will be forced to manually fix it again next time.
